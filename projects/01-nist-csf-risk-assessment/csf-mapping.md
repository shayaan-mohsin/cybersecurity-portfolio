# Using NIST CSF 2.0 to organize the questions

[Project overview](README.md) · [Risk register](risk-register.md)

The [NIST Cybersecurity Framework 2.0](https://doi.org/10.6028/NIST.CSWP.29) describes cybersecurity outcomes. It organizes this discussion; it is not a certification or a substitute for a regulatory assessment.

| Function | Question for the hypothetical organization | Evidence to request |
| --- | --- | --- |
| Govern | Who owns sensitive-data risks and exceptions? | Named owners, approved policy, supplier responsibilities |
| Identify | Which systems, identities, and data flows matter? | Current inventories and business-service dependencies |
| Protect | How is access granted, reviewed, and recovered? | Access reviews, recovery controls, configuration evidence |
| Detect | Which changes and unusual actions are visible? | Log-source coverage, alert tests, investigation records |
| Respond | Who investigates and communicates during disruption? | Response roles, escalation criteria, exercise observations |
| Recover | Can the affected service be restored safely? | Restore-test results, integrity checks, service-owner acceptance |

The mapping is at the function level. It does not claim that a CSF subcategory or a HIPAA requirement has been satisfied.
